# LangChain App Tracing with LangSmith

A beginner-friendly Python project demonstrating how to build a LangChain application and trace its execution using LangSmith.

## 🚀 Project Overview

This application accepts a user question, sends it to an OpenAI chat model through LangChain, and returns an AI-generated response.

LangSmith tracing allows you to monitor and debug the execution of your LangChain application.

### Features

- Build an LLM pipeline using LangChain.
- Integrate OpenAI's chat model.
- Enable LangSmith tracing.
- Inspect prompts, inputs, outputs, and execution runs.
- Add custom run names, tags, and metadata.
- Debug application errors.

## 🛠️ Tech Stack

- Python
- LangChain
- OpenAI API
- LangSmith
- python-dotenv

Before running the project, make sure you have:

## ⚙️ Installation

### Step 1: Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd langchain-tracing
```

If you have not uploaded the project to GitHub yet, create the folder and open it in VS Code.

### Step 2: Create a virtual environment

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Step 3: Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Step 4: Configure environment variables

Create a `.env` file in the root directory:

```dotenv
OPENAI_API_KEY=your_openai_api_key
LANGSMITH_API_KEY=your_langsmith_api_key
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=My-LangChain-Trace
```

Replace the example values with your actual API keys.

**Security:** Never commit your `.env` file or publish API keys in your repository.

### Step 5: Run the application

```bash
python app.py
```

Enter a question when prompted:

```text
Ask a question: What is Retrieval-Augmented Generation?
```

The application prints the AI-generated response in your terminal.

## 🔍 View Traces in LangSmith

1. Open [LangSmith](https://smith.langchain.com/).
2. Sign in to your account.
3. Open the project named `My-LangChain-Trace`.
4. Find the run generated by your application.
5. Inspect inputs, outputs, execution time, and model usage details when available.

## 🐛 Troubleshooting

### Missing API key

Check that `.env` exists in the project root and contains valid API keys.

### Module not found

Activate your virtual environment and install dependencies:

```bash
pip install -r requirements.txt
```

### No traces appearing

- Confirm `LANGSMITH_TRACING=true`.
- Verify that `LANGSMITH_API_KEY` is valid.
- Check that your network allows connections to LangSmith.
- Confirm that the application completed a traced run and allow time for trace ingestion.
- Check the selected LangSmith project name.

### OpenAI API errors

Verify your API key, model access, available API quota, and billing configuration.
